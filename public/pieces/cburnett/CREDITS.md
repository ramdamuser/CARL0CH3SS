# Cburnett chess pieces

The 12 SVG chess pieces in this directory were created by Colin M. L. Burnett and obtained unmodified from [Lichess's Cburnett piece set](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett).

Lichess lists this set as [GPLv2 or later](https://github.com/lichess-org/lila/blob/master/COPYING.md). The licence text is included in [LICENSE.txt](LICENSE.txt). The SVG files are the preferred source form for these images.
